Postgres 是一个开源的关系型数据库，支持通过 pgvector 扩展存储向量并做相似度检索。
向量检索的核心思路：把文本变成一串数字（embedding），语义相近的文本在向量空间里距离也相近。
BM25 是一种基于关键词匹配和词频统计的经典检索算法，不需要模型，胜在可解释、对精确关键词很敏感。
RAG（检索增强生成）把"检索"和"大模型生成"结合起来：先找到相关资料，再让模型基于这些资料回答问题。
向量检索擅长找"意思相近"的内容，BM25 擅长找"关键词精确匹配"的内容，实际系统里常把两者结合使用。
Neo4j 是一个图数据库，适合表达实体之间的关系，例如"谁是谁的同事"“哪个零件属于哪个产品”。
Docker 可以把数据库、依赖环境打包成容器，本地一条命令就能启动，不用手动安装配置。
embedding 模型会把任意长度的文本压缩成一个固定长度的向量，常见维度有 384、768、1536 等。
