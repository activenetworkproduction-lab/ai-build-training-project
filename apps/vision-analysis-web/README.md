# 项目一：图片内容识别与分析（教学项目）

上传一张图片，让视觉大模型（Gemini 3.5 Flash / OpenAI 视觉模型）描述画面内容并给出更深一层的分析。

> Gemini 2.5 Flash 已对新用户下线，本项目改用仍可用的 gemini-3.5-flash（和 OCR 项目一致）。

## 与 OCR 项目（apps/ocr-web）的区别

两个项目的上传/配置/展示 UI 结构几乎一样，区别在于"问模型什么问题"：

| | OCR 项目 | 本项目 |
|---|---|---|
| 目标 | 把图片里的文字原样抄出来 | 描述图片内容 + 给出分析 |
| 支持的服务商 | Gemini / Qwen-VL | Gemini / OpenAI |
| 输出结构 | `{ text }` | `{ description, analysis }` |
